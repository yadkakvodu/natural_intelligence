# Уведомление о сторонних компонентах (Third Party Notices)

Данный документ содержит перечень всех сторонних компонентов, моделей искусственного интеллекта, фреймворков, библиотек и наборов данных, использованных при разработке решения «Новостной консультант Альфа-Банка» в рамках хакатона «Альфа Будущее».

## 1. Модели искусственного интеллекта (LLM и Embeddings)

Использование моделей строго ограничено списком, разрешенным организаторами кейса (Приложение 3).

| Компонент | Назначение | Лицензия / Условия использования |
|-----------|------------|----------------------------------|
| **DeepSeek-V3** (или DeepSeek-V4.1-Flash) | Основная модель (Primary) для генерации бизнес-инсайтов и ответов в чате. | Используется через API, предоставленный организаторами. Ограничение бюджета: 500 руб./сутки. |
| **Qwen2.5-72B-Instruct** (или Qwen3.6 35B A3B) | Резервная модель (Fallback) при недоступности основной модели или для задач повышенной сложности. | Используется через API, предоставленный организаторами. |
| **BAAI/bge-m3** | Генерация векторных представлений (embeddings) текстов для RAG-поиска (размерность 1024). | MIT License. Локальное использование или через разрешенный API. |

*Примечание: Внешние автономные AI-агенты и готовые мультиагентные системы не использовались. Логика планирования, RAG-поиска и самопроверки реализована командой самостоятельно.*

## 4. Наборы данных (Datasets) и исходные материалы

Все данные используются исключительно в обезличенном виде в рамках правил хакатона и не содержат персональной информации (PII).

| Источник | Описание | Правообладатель / Условия |
|----------|----------|---------------------------|
| `df_Uid_data_hack.csv` | Обезличенные данные о юридических лицах (ОКВЭД, продукты, выручка, признаки ВЭД). | Предоставлено организаторами кейса (АО «Альфа-Банк»). Только для целей хакатона. |
| `df_Fid_Uid_link_hack.csv` | Обезличенные данные о связанных физических лицах. | Предоставлено организаторами кейса. Только для целей хакатона. |
| `df_Uid_payment_hack.csv` | Обезличенные данные о платежах между компаниями. | Предоставлено организаторами кейса. Только для целей хакатона. |
| Аналитические материалы Альфа-Банка (PDF) | Набор из 9 документов Центра макроэкономических исследований (например, «Ключевая ставка ЦБ РФ: ставка без изменения»). | Предоставлено организаторами кейса. Используется для RAG-поиска и формирования экспертной позиции. |

## 5. Симулированные интеграции и внешние сервисы

| Компонент | Описание |
|-----------|----------|
| **Внешние новости (CSV)** | Симулированный поток внешних новостей (СМИ, регуляторы), созданный командой на основе открытых данных для демонстрации работы RAG-поиска. Не является реальным парсингом в реальном времени. |
| **LLM API Gateway** | Абстрагированный шлюз для вызова разрешенных LLM. В демо-режиме может использовать моки или тестовые ключи, предоставленные организаторами. |
