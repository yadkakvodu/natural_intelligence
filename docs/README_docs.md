# Natural Intelligence — Структура проекта

## Описание папок репозитория

###  `backend-java/`
Бэкенд-часть проекта на Java (Spring Boot). Содержит REST API, веб-контроллеры, бизнес-логику, DTO, сущности БД, репозитории и статические файлы фронтенда (HTML/CSS/JS).

### 📁 `ai-core-python/`
AI-ядро на Python. Отвечает за обработку данных, парсинг PDF, работу с языковыми моделями (LLM) и генерацию инсайтов.

### 📁 `docs/`
Общая документация проекта. Содержит описание архитектуры (`architecture.md`), SQL-скрипты инициализации БД (`db/init.sql`), OpenAPI-спецификацию и диаграммы.

### 📁 `src/` (внутри backend-java)
Стандартная структура Maven-проекта:
- `main/java/` — исходный код Java
- `main/resources/` — конфигурации, шаблоны HTML, статика (CSS, JS, картинки)
- `test/java/` — тесты

### 📁 `docs/db/`
Файлы, связанные с базой данных: скрипты создания таблиц (DDL) и инициализации.

### 📁 `docs/api/`
Спецификация API в формате OpenAPI (Swagger).

### 📁 `docs/diagrams/`
Диаграммы архитектуры проекта в нотации C4 (контекстные и компонентные).

### 📁 `ai-core-python/`
- `requirements.txt` — зависимости Python
- Скрипты для работы с PDF и AI-логикой
